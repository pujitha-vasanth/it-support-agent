IT Support Agent

Answers IT questions from a 400-page policy and runbook set, and triages tickets into a human approval queue. Every answer cites its source, and says so when the documents do not cover it. All data is synthetic.

How long does a VPN session last? How do I request access to a shared drive? What is the parking policy?

Live, last 24 hours

Quality bar enforced on every change

Every code change re-runs the 50-question golden set and the 50 labelled tickets. If any score falls below this bar, the change is blocked.

Source and evaluation method: github.com/pujitha-vasanth/it-support-agent · API docs at /docs
